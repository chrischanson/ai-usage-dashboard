# Vendored Frontend Libraries

This directory contains vendored client-side JavaScript libraries used by the AI Usage Dashboard.

| Library | Version | License | Upstream URL | Purpose |
|---|---|---|---|---|
| **Chart.js** | v4.5.1 | MIT | [https://www.chartjs.org](https://www.chartjs.org) | Canvas-based rendering of historical usage line and donut charts. |
| **Hammer.JS** | v2.0.7 | MIT | [http://hammerjs.github.io](http://hammerjs.github.io/) | Multi-touch gesture recognition support for pan and pinch-zoom. |
| **chartjs-plugin-zoom** | v2.0.1 | MIT | [https://www.chartjs.org](https://www.chartjs.org) | Chart.js plugin enabling pan and zoom interactions on charts. |
